# Eric Chennells

Security consultant in Vancouver, BC. I run [Runlevel Security](https://runlevelsecurity.com), build payment tools for AI agents, and do agentic testing and hardening of Bitcoin node software with [libbitcoin](https://github.com/libbitcoin).

## Building

- **[sparkbtcbot](https://github.com/echennells/sparkbtcbot)**: a self-custodial Bitcoin wallet for AI agents on the Spark L2. Agents can pay Lightning invoices and L402 paywalls, and buy gift cards, eSIMs and VPNs. On [npm](https://www.npmjs.com/package/sparkbtcbot-skill) and as a Claude Code plugin. [Project site](https://sparkbtcbot.yvrbtclabs.dev).
- **[supply-chain-hardening](https://github.com/echennells/supply-chain-hardening)**: safe defaults for 14 package managers, plus a verifier that asks each tool what it's actually enforcing. Ships as an Ansible role and a GitHub Action for servers, AI-agent hosts and CI.
- **[taproot_assets](https://github.com/echennells/taproot_assets)**: a Taproot Assets extension for LNbits.
